# Implementation contracts

## macOS interface conventions

The local 0.2.1 [macOS design audit](MACOS_DESIGN_AUDIT.md) identifies the native-window, menu and caption-rendering boundaries involved in the proposed fixes. Apple’s Media Accessibility framework exposes the viewer’s caption preferences to a custom renderer. Apple describes a dedicated Mac Settings window that restores its last pane, and allows a permanently dark appearance for immersive media. These are design references for future work. [Caption preferences](https://developer.apple.com/documentation/mediaaccessibility/captions) · [Settings](https://developer.apple.com/design/human-interface-guidelines/settings) · [Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode).

## Runtime

Rust owns the canonical camelCase wire and disk types in `hlp-core`. The UI mirrors them in `app/ui/src/lib/types.ts`. Every pipeline event carries its session ID. Times are milliseconds from the start of the media. Sample offsets always refer to mono signed little-endian 16-bit PCM at 16 kHz.

The desktop WebView supplies the current catalog’s labels to the native menu after loading preferences and on each interface language change. Rust binds those labels to the same action IDs and accelerators each time. Window and Help retain their Tauri menu IDs so macOS can attach its system entries. The macOS bundle declares the localizations handled by the app for system-owned UI. File picker titles and filters come from the player catalog. [Tauri menu reference](https://docs.rs/tauri/latest/tauri/menu/index.html) · [Apple bundle localizations](https://developer.apple.com/documentation/bundleresources/information-property-list/cfbundlelocalizations) · [Tauri macOS bundle configuration](https://v2.tauri.app/reference/config/#macconfig).

The macOS welcome action uses the mixed picker in the locked rfd 0.17.2 dependency. It enables both file and directory selection in a single AppKit panel. Selected files enter the queue directly, and selected directories contribute their playable children. The recent-file reveal action uses the existing native opener, which selects the file in Finder via NSWorkspace. [rfd macOS picker](https://docs.rs/crate/rfd/0.17.2/source/src/backend/macos/file_dialog/panel_ffi.rs) · [Tauri opener](https://docs.rs/tauri-plugin-opener/2.7.3/tauri_plugin_opener/fn.reveal_item_in_dir.html).

One shared ASR client and one llama-server serve successive sessions. The worker protocol is line-delimited JSON with monotonically assigned request IDs. A session owns the selected file, track, playhead and cache lifetime. The desktop and CLI use the same session. The local media server issues per-registration opaque URLs and serves byte ranges.

The desktop package ships FFmpeg and FFprobe beside the executable. Model Setup installs the checksum-verified Silero speech detector on demand. The player uses them for format detection, playback conversion, chapters, frame capture and embedded text subtitles on first launch. A local media session can run with an empty model directory. The speech and translation models and optional URL tools use `HLP_OMINIX_ROOT` when set. Caches, settings and recently opened items live in the platform application data directory.

The desktop receives file paths from the operating system, its file and folder dialogs, or the command line. The frontend owns the playlist, per-file resume positions and subtitle choices. The session owns playback preparation and generated captions. Embedded and neighboring text tracks come from the original file and its directory. Selected external SRT and WebVTT contents are retained in the WebView’s local IndexedDB. Authored subtitles use the same adjusted cue times for the overlay, transcript and picture-in-picture. Lane-local fixture tests read generated speech and its onset truth from `tests/fixtures`.

On macOS, the combined media picker uses the locked rfd 0.17.2 async dialog. Its AppKit panel allows both files and directories and supports multiple selections. The player expands each selected directory into its playable children in natural order. A single selected file still loads the neighboring playlist. On platforms with separate native pickers, the welcome action offers both choices. [rfd file and folder picker](https://docs.rs/rfd/0.17.2/rfd/struct.AsyncFileDialog.html#method.pick_files_or_folders).

The floating Picture in Picture window uses the native video presentation API. On macOS, Close (×) pauses the video and Restore returns a playing video to the main window with playback continuing. The frontend updates its button state and caption track when the presentation changes. [Apple’s Safari User Guide](https://support.apple.com/guide/safari/play-web-videos-ibrw27291639/mac).

The playback output menu uses WebKit’s wireless-target availability and current-route events while the menu is open. Selecting an available AirPlay route invokes the native picker directly from the user gesture. WKWebView permits AirPlay by default. Device discovery and route selection run through the operating system. [Apple’s custom AirPlay controls](https://developer.apple.com/documentation/webkitjs/adding_an_airplay_button_to_your_safari_media_controls) · [WKWebView AirPlay configuration](https://developer.apple.com/documentation/webkit/wkwebviewconfiguration/allowsairplayformediaplayback).

The session media server binds to the Mac’s loopback interface. An AirPlay receiver that fetches media by URL cannot retrieve that address from the Mac. WebKit documents URL handoff for web video. Device selection in the WebView and end-to-end playback of a local file on a particular receiver require separate verification. [WebKit’s explanation of AirPlay source URLs](https://webkit.org/blog/15036/how-to-use-media-source-extensions-with-airplay/).

For direct MP4 playback on macOS, WebKit obtains the video element’s playback-quality counters from its AVPlayerLayer. A display-deadline miss can increment the dropped-frame count while the media clock continues and buffered data remains available. WebKit also uses a video output to supply frame callbacks, so callback intervals and output timestamps measure a different part of the path. For frame-pacing investigations, compare the layer counters with the same file, display, window size and playback rate, including a run without frame callbacks. [WebKit’s AVFoundation playback implementation](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/platform/graphics/avfoundation/objc/MediaPlayerPrivateAVFoundationObjC.mm) · [Apple’s video performance metrics](https://developer.apple.com/documentation/avfoundation/avvideoperformancemetrics).

Double-clicking the picture or pressing F calls Tauri’s window fullscreen API. In the pinned Tao 0.37.3 Mac backend, programmatic entry and the green window button both use AppKit fullscreen. Tao applies the latest request made during a transition after AppKit finishes and emits a resize event on completion. The webview observes native window state to update its controls after a system menu or title-bar action. [Tauri window API](https://v2.tauri.app/reference/javascript/api/namespacewindow/#setfullscreen) · [AppKit fullscreen action](https://developer.apple.com/documentation/appkit/nswindow/togglefullscreen%28_%3A%29).

Windowed playback follows the video element’s natural dimensions in CSS pixels, including its pixel aspect ratio. The element reports changes to those dimensions through its own resize event. AppKit constrains the full window frame because the video extends under the overlay title bar. Resetting the window’s resize increments releases the constraint for the welcome and audio views. On Windows a subclass on the window’s UI thread adjusts each proposed sizing rectangle after subtracting the native frame and caption. [HTML video dimensions](https://html.spec.whatwg.org/multipage/media.html#dom-video-videowidth) · [AppKit aspect ratio](https://developer.apple.com/documentation/appkit/nswindow/aspectratio) · [Windows sizing message](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-sizing) · [Windows subclass API](https://learn.microsoft.com/en-us/windows/win32/api/commctrl/nf-commctrl-setwindowsubclass).

The timeline takes a snapshot of the video element’s buffered ranges on metadata, progress, seek completion and source reset. Each range keeps its own start and end, so seeking ahead leaves unbuffered gaps visible. The separate strip beneath the timeline uses subtitle pipeline progress. [HTML media buffered ranges](https://html.spec.whatwg.org/multipage/media.html#dom-media-buffered)

The desktop frontend uses Svelte 5. The Settings tab selection moves a single highlight behind the button labels. The transport crossfades the video blur and the foreground controls on the same timeline. Its enclosing slot stays at full opacity so the blur can sample the video throughout the reveal. The CSS Filter Effects draft describes how a partially transparent ancestor limits backdrop sampling. The Gooey reference implements its effects as React components. These interactions use local CSS and require no additional runtime. [Filter Effects, Backdrop Root](https://drafts.csswg.org/filter-effects-2/#BackdropRoot) · [Gooey](https://libraries.dev/gooey)

## Online subtitle search

**Find Online Subtitles** runs only after a viewer submits a title or IMDb ID. By default the desktop queries Subtitle Search Engine’s documented guest endpoint. It sends the edited query and optional language and requests SRT files. Each result identifies a release. Choosing a file requests its download ticket and then retrieves the subtitle from the provider’s uploads directory. Chinese results use the generic `zh` language code. The API’s reported allowance and its documented guest limit can differ, so the UI reports rate-limit errors without promising a fixed number of downloads. [Subtitle Search Engine API](https://subtitles.website/docs/).

Deployments that already set `OPENSUBTITLES_API_KEY` keep the direct OpenSubtitles.com integration. The desktop reads this setting from its environment and attaches it only to API-origin requests. The player never asks a viewer for a key. [OpenSubtitles API guide](https://opensubtitles.tawk.help/article/getting-started).

The selected file enters the same cue parser and per-movie IndexedDB store as a local SRT. Provider-prefixed track IDs keep each service’s releases distinct and preserve earlier imports. Playback of a saved track works offline. Remote responses use bounded reads, provider-specific HTTPS origin checks and the local importer’s 16 MiB subtitle limit. Media files, audio and directory paths stay on the device.

## Build observations

On macOS, the app bundle names `AppIcon` in `CFBundleIconName`. Its compiled `Assets.car` contains the light, dark and tintable stacks from `app/icons/AppIcon.icon`. Finder and the Dock render those layers with the system appearance, including the system-supplied background in Clear mode. The app bundles a white-and-blue ICNS for older Macs. Tauri sets a static Dock image only when running its development executable. The welcome screen uses a separate foreground image with transparent space between the footprints and playback controls. The Windows executable and NSIS installer use the ICO. [Apple’s Icon Composer documentation](https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer) · [Tauri’s macOS icon bundler](https://github.com/tauri-apps/tauri/blob/tauri-cli-v2.12.6/crates/tauri-bundler/src/bundle/macos/icon.rs).

The macOS theme option **Follow System** reads `NSColor.controlAccentColor` in sRGB. A process-wide AppKit observer sends updated colors to the webview on `NSColor.systemColorsDidChangeNotification`. Each webview subscribes before requesting its initial value, so reopening a window picks up changes made while it was closed. The logo and selection swatch use the resolved color, and text and small indicators get lighter shades when needed for contrast on glass. The Dock’s icon and widget style is a separate system preference. [Control accent](https://developer.apple.com/documentation/appkit/nscolor/controlaccentcolor) · [System color changes](https://developer.apple.com/documentation/appkit/nscolor/systemcolorsdidchangenotification) · [Mac appearance preferences](https://support.apple.com/guide/macbook-pro/apd2add7474b/mac).

The pinned upstream MLX release includes libmlx.a, libmlxc.a, libgguflib.a and mlx.metallib. The translator release workflow supplies the SHA-256 for the build archive. A Command Line Tools installation can supply clang on hosts where full Xcode is unavailable. The installed Homebrew FFmpeg on the development Mac omits libvpx. The fixture generator accepts an encoder-capable FFmpeg via HLP_FFMPEG.

## Interface languages

The language picker uses the 30 spoken-language entries in the player’s Qwen3-ASR table. Cantonese has its own catalog. The 22 Chinese regional accents listed on the model card are recognition variants. The app bundles its interface translations locally and uses the same catalog for the webview and its native menu commands. System mode matches the user’s preferred languages in order. Arabic and Persian use right-to-left layout, and the media timeline keeps its playback direction. [Qwen3-ASR model card](https://huggingface.co/Qwen/Qwen3-ASR-1.7B)

## Verification notes

- On macOS, the pinned `sys-locale` implementation reads the ordered list from `CFLocaleCopyPreferredLanguages`. Fresh subtitle settings select the first language in that list that Hy-MT2 can produce. The browser preview applies the same selection to `navigator.languages`. Existing settings store concrete language codes.

- sherpa-onnx 2.0.3 exposes `OfflineModelConfig::qwen3_asr` with convolutional frontend, encoder, decoder and tokenizer paths. The Rust VAD API gives the global segment start in samples and sample count through `start()` and `n()`.
- The local Qwen3-ASR generation config lists EOS IDs 151643 and 151645. The tokenizer config includes the added token `<asr_text>`.
- The Section 8.3 example using FFmpeg's null muxer fails even for a valid, single-cue SRT with “Output file does not contain any stream.” Explicitly mapping the subtitle stream and decoding to WebVTT verifies parsing and produces the expected cue. The E2E oracle uses `-map 0:s:0 -c:s webvtt -f webvtt -` for nonempty exports.
- The GGUF's pinned LICENSE.txt declares Apache-2.0, and yt-dlp's packaged binary includes GPL components. See [the license inventory](LICENSES.md).
- Hy-MT2's English default prompt has a space between its two instruction sentences and a blank line before the source. The implementation uses the verified default and Structured Data 2 templates. [Upstream instructions at the reviewed revision](https://github.com/Tencent-Hunyuan/Hy-MT2/blob/ff1903ecaa724e10951a23c16817a2413c752b35/README.md).
- Both MLX variants use the same ten pinned runtime and model-card filenames. The two providers use separate immutable revisions with matching contents. The Windows ASR tarball contains three ONNX graphs and the three tokenizer files. Exact archive sizes and digests are in the component catalog.
- FFprobe shares one container name for WebM and Matroska. The EBML DocType distinguishes them. Timestamp-aware 16 kHz resampling keeps PCM aligned across discontinuous AAC packets. The Range server supplements ServeFile with If-Range validation.
- Some existing tokenizer.json files discard the ASR delimiter during skip-special decoding. The worker rebuilds the tokenizer in memory from the original pinned vocabulary, merges and token configuration. Real automatic inference returns the expected language header.
- Native objects and Metal kernels in the upstream prebuilt archive target macOS 15. The developer and packaging scripts build MLX 0.30.1 for macOS 14, with SHA-verified kernels from the corresponding official wheel. The build and fixture recognition passed on the development Mac using the standalone macOS 14.4 SDK. A Sonoma hardware run is outstanding. [Native patch notes](../vendor/qwen3-asr-mlx/PATCHES.md).

## Session and cache

The CLI requests transcription when it opens a session. The desktop first opens for playback and discovers authored tracks. An explicit generation request checks the selected components and starts extraction in the active session, preserving the video URL and playhead. Each audio track records an accepted request so later sessions can resume or reuse the generated lines. Both interfaces use the same session task. A bounded 64-frame channel connects FFmpeg extraction and the Silero thread. Each audio track has its own PCM file, VAD segments, transcript and translations. Its playback index also records the preparation plan and browser capabilities, so switching back can immediately serve a compatible cached video. A file lock protects an open project from competing writers and cache eviction. Session shutdown joins outstanding media work before releasing the lock.

With dialogue context enabled, translation includes up to three previous recognized utterances from the same audio track and source language. The window extends up to 30 seconds before the current utterance and ends at an eight-second gap or a missing line. The background is limited to 1,024 UTF-8 bytes. Hy-MT2 receives the previous dialogue as background and the current utterance as its translation input. When a seek changes the order of recognition, the scheduler refreshes translations whose inputs changed. The track stores these results in a separate language-specific context cache. A user can switch modes while keeping the transcription and display the last available translations during processing.

If Hy-MT2 returns an empty answer, reasoning alone, or echoes text containing letters across languages, the translator retries with the spoken fragment and its language pair. A second rejected answer marks that utterance as untranslated. The scheduler continues through the remaining dialogue and reports `partial` once all other work finishes. The subtitle panel then offers **Retry Untranslated Lines**. An explicit CLI rerun also retries those entries from the saved transcript. A translation service failure that persists across connection retries stops the job and exposes the underlying error.

On macOS, slow speech recognition gets priority over background translation while audio is playing. After processing eight seconds of speech, the scheduler defers new background translations if ASR is below 8× and extracted speech inside the lookahead still needs recognition. Translations for the current line and the next two seconds remain eligible.

A saved transcript records the model, VAD hash and source-language mode. Changing a forced language on macOS queues the affected rows and retains their text as stale until recognition finishes. An automatic language probe without a majority at six eligible utterances waits for twelve. Cache hits publish the restored cues with the opening event and require no engine requests. An explicit regeneration assigns a new generation ID to the current audio track’s transcript and reuses its PCM and detected speech regions. Translations are valid only for the saved generation, including when switching languages or resuming after a quit. Older caches without an ID use generation zero.

The session rebuilds generated subtitles from each recognized utterance and its translation. It pairs complete sentences and looks for corresponding clause boundaries using punctuation and connectors. The layout pass subdivides long aligned spans at word or clause boundaries in both languages, taking shared names and numbers into account. It can allow a longer cue when an English and Chinese clause change order. The same pass runs when restoring cached utterances and before export. For newly translated pairs exceeding 120 display columns after clause matching, the pipeline translates shorter source phrases with the complete utterance as background. Their translations help locate phrase boundaries within the full translation. The track saves the full translation verbatim and stores accepted source and target offsets alongside it. Source-only captions can split at word boundaries detected by the embedded ICU4X dictionary. Timing within an utterance is estimated from the source text and speech intervals. [ICU4X dictionary segmentation](https://docs.rs/icu_segmenter/2.4.0/icu_segmenter/struct.WordSegmenter.html#method.new_dictionary).

Deleting generated subtitles clears the current audio track’s saved transcript, alternate ASR-model transcripts, translations in every target language and the request to resume generation. The session keeps the media open and retains decoded audio for a later transcription request. A marker in the track cache lets an interrupted deletion finish on the next open. Imported tracks and exported files are stored separately.

Desktop generation saves timed utterances in the movie’s per-audio-track cache and translations under the corresponding target language. An SRT beside the movie is an explicit export. During ordinary playback both cached and imported text use an HTML overlay above the decoded video. Native media time updates keep the transport synchronized. A separate timer checks the media clock at subtitle starts, ends and overflow page changes so even brief cues can appear between time updates. Visible controls can sample the clock more often when a short or accelerated clip moves the scrubber several pixels between updates. Hidden controls stop sampling it.

The frontend sends the current playhead to the scheduler while inference is active and on transport or generation commands. A completed, saved session waits for commands without periodic scheduler ticks. Active model users share the ASR worker and local translation server. When the last user releases them, a 30-second grace period allows another generation to reuse the loaded models. On expiry the worker processes shut down. The media server continues serving the video.

Generated subtitles replace sentence punctuation with spaces after determining cue boundaries. Lexical apostrophes, numeric separators and other meaningful marks survive. The overlay centers each language on one row within the video picture. Text size depends on the picture dimensions, user setting and row order. If a generated line still exceeds its measured pixel width, the overlay shows successive parts during that cue, keeping each row at its selected size. It reserves a row while translation runs. The default bottom offset is 5% of picture height. Visible playback controls add clearance only where they overlap the chosen position. SRT, VTT and ASS exports emit one row per language. Viewers can select the source, the target or both. An imported subtitle file keeps its own cue times, punctuation and explicit line breaks.

During transcription the session retains each utterance’s segmented phrases and invalidates them when the utterance or its translation changes. Neighboring cues still participate in timing and merging. The sidebar renders a window of timed rows near the scroll position. The transport maps outstanding work to a small canvas strip at its displayed width. In audio-only playback, a search of the sorted track finds the phrase at the playhead and up to four neighbors. These five phrases use the same track, language preferences and timing offsets as video captions.

The fixture oracle decodes subtitle streams explicitly with FFmpeg's WebVTT encoder. FFmpeg's null muxer has no default subtitle codec and reports “Output file does not contain any stream” for a valid subtitle-only input.


## Regional model downloads and public updates

Model Setup uses immutable artifact URLs with a shared byte count and SHA-256 across providers. Automatic mode uses the operating system locale region to give the corresponding source a short head start when probing an actual file. A slow response lets the other source compete. Manual region selection takes precedence. A failed download can resume against the other source and still has to pass the same digest check. Playback, an existing complete model installation, and simply opening Setup do not probe either service. The Apple Silicon Qwen and Hy-MT2 files are available through Hugging Face and ModelScope. Silero also has a verified domestic mirror. [Qwen on Hugging Face](https://huggingface.co/mlx-community/Qwen3-ASR-1.7B-8bit) · [Qwen on ModelScope](https://modelscope.cn/models/mlx-community/Qwen3-ASR-1.7B-8bit) · [Hy-MT2 on ModelScope](https://modelscope.cn/models/Tencent-Hunyuan/Hy-MT2-1.8B-GGUF)

The desktop reads its installed version locally. A manual update check, or an explicitly enabled automatic check, reads the public GitHub Releases API for the repository named in `app/release-repository.txt`. Only published stable releases appear. Installing a newer version requires its platform archive, version-bound signature and `latest.json`. The client verifies size, SHA-256 and the publisher signature before installation. Updating and ordinary playback require no purchase or account. [GitHub Releases API](https://docs.github.com/en/rest/releases/releases#list-releases) · [Tauri updater](https://v2.tauri.app/plugin/updater/)

The Apple Silicon installer builds FFmpeg and FFprobe from pinned FFmpeg and dav1d source archives. The app includes these archives and its build recipe in `Contents/Resources/licenses/FFmpeg-sources`. The CLI’s separate setup flow still offers the pinned OSXExperts binaries.
