# Implementation contracts

Rust owns the canonical camelCase wire and disk types in `hlp-core`. The UI mirrors them in `app/ui/src/lib/types.ts`. Every pipeline event carries its session ID. Times are milliseconds from the start of the media. Sample offsets always refer to mono signed little-endian 16-bit PCM at 16 kHz.

One shared ASR client and one llama-server serve successive sessions. The worker protocol is line-delimited JSON with monotonically assigned request IDs. A session owns the selected file, track, playhead and cache lifetime. The desktop and CLI use the same session. The local media server issues per-registration opaque URLs and serves byte ranges.

The desktop package ships FFmpeg and FFprobe beside the executable and includes a checksum-verified Silero speech detector in its resources. The player uses them for format detection, playback conversion, chapters, frame capture and embedded text subtitles on first launch. A local media session can run with an empty model directory. The speech and translation models and optional URL tools use `HLP_OMINIX_ROOT` when set. Caches, settings and recently opened items live in the platform application data directory.

The desktop receives file paths from the operating system, its file and folder dialogs, or the command line. The frontend owns the playlist, per-file resume positions and subtitle choices. The session owns playback preparation and generated captions. Embedded and neighboring text tracks come from the original file and its directory. Selected external SRT and WebVTT contents are retained in the WebView’s local IndexedDB. Authored subtitles use the same adjusted cue times for the overlay, transcript and picture-in-picture. Lane-local fixture tests read generated speech and its onset truth from `tests/fixtures`.

## Build observations

The pinned upstream MLX release includes libmlx.a, libmlxc.a, libgguflib.a and mlx.metallib. The translator release workflow supplies the SHA-256 for the build archive. A Command Line Tools installation can supply clang on hosts where full Xcode is unavailable. The installed Homebrew FFmpeg on the development Mac omits libvpx. The fixture generator accepts an encoder-capable FFmpeg via HLP_FFMPEG.

## Verification notes

- sherpa-onnx 2.0.3 exposes `OfflineModelConfig::qwen3_asr` with convolutional frontend, encoder, decoder and tokenizer paths. The Rust VAD API gives the global segment start in samples and sample count through `start()` and `n()`.
- The local Qwen3-ASR generation config lists EOS IDs 151643 and 151645. The tokenizer config includes the added token `<asr_text>`.
- The Section 8.3 example using FFmpeg's null muxer fails even for a valid, single-cue SRT with “Output file does not contain any stream.” Explicitly mapping the subtitle stream and decoding to WebVTT verifies parsing and produces the expected cue. The E2E oracle uses `-map 0:s:0 -c:s webvtt -f webvtt -` for nonempty exports.
- The GGUF's pinned LICENSE.txt declares Apache-2.0, and yt-dlp's packaged binary includes GPL components. See [the license inventory](LICENSES.md).
- Hy-MT2's English default prompt has a space between its two instruction sentences and a blank line before the source. The implementation uses the verified default and Structured Data 2 templates. [Upstream instructions at the reviewed revision](https://github.com/Tencent-Hunyuan/Hy-MT2/blob/ff1903ecaa724e10951a23c16817a2413c752b35/README.md).
- Both MLX variants use the same ten pinned runtime and model-card filenames. The two providers use separate immutable revisions with matching contents. The Windows ASR tarball contains three ONNX graphs and the three tokenizer files. Exact archive sizes and digests are in the component catalog.
- FFprobe shares one container name for WebM and Matroska. The EBML DocType distinguishes them. Timestamp-aware 16 kHz resampling keeps PCM aligned across discontinuous AAC packets. The Range server supplements ServeFile with If-Range validation.
- Some existing tokenizer.json files discard the ASR delimiter during skip-special decoding. The worker rebuilds the tokenizer in memory from the original pinned vocabulary, merges and token configuration. Real automatic inference returns the expected language header.
- Native objects and Metal kernels in the upstream prebuilt archive target macOS 15. The developer and packaging scripts build MLX 0.30.1 for macOS 14, with SHA-verified kernels from the corresponding official wheel. The build and fixture recognition passed on the development Mac using the standalone macOS 14.4 SDK. A Sonoma hardware run is outstanding. [Native patch notes](../vendor/qwen3-asr-mlx/PATCHES.md).

## Session and cache

The CLI requests transcription when it opens a session. The desktop first opens for playback and discovers authored tracks. An explicit generation request checks the selected components and starts extraction in the active session, preserving the video URL and playhead. Each audio track records an accepted request so later sessions can resume or reuse the generated lines. Both interfaces use the same session task. A bounded 64-frame channel connects FFmpeg extraction and the Silero thread. Each audio track has its own PCM file, VAD segments, transcript and translations. Its playback index also records the preparation plan and browser capabilities, so switching back can immediately serve a compatible cached video. A file lock protects an open project from competing writers and cache eviction. Session shutdown joins outstanding media work before releasing the lock.

On macOS, slow speech recognition gets priority over background translation while audio is playing. After processing eight seconds of speech, the scheduler defers new background translations if ASR is below 8× and extracted speech inside the lookahead still needs recognition. Translations for the current line and the next two seconds remain eligible.

A saved transcript records the model, VAD hash and source-language mode. Changing a forced language on macOS queues the affected rows and retains their text as stale until recognition finishes. An automatic language probe without a majority at six eligible utterances waits for twelve. Cache hits publish the restored cues with the opening event and require no engine requests.

The session rebuilds generated subtitle cues from the saved utterances and translations. It first pairs sentences, then splits long pairs near punctuation or whole-word boundaries, aiming for 56 display columns per language per cue. An embedded ICU4X dictionary finds word boundaries in unspaced Chinese, Japanese and other supported scripts. The split times are estimates based on source text width and detected speech intervals. A short indivisible word stays with its translation, and brief neighboring cues can share screen time. The overlay constrains each language to a readable width, including in fullscreen. Generated exports wrap lines at 42 display columns. An imported subtitle file keeps its own cue times and explicit line breaks. [ICU4X dictionary segmentation](https://docs.rs/icu_segmenter/2.4.0/icu_segmenter/struct.WordSegmenter.html#method.new_dictionary).

The fixture oracle decodes subtitle streams explicitly with FFmpeg's WebVTT encoder. FFmpeg's null muxer has no default subtitle codec and reports “Output file does not contain any stream” for a valid subtitle-only input.
